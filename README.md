# Words Collector

一个无需构建步骤的 Chrome Manifest V3 扩展。开启收集开关后，在普通网页双击或鼠标拖拽选中文字，会在选区旁出现「收集」按钮；只有点击该按钮，才会把文字保存到扩展的本地存储。首次安装时开关默认关闭。

## 安装

1. 在 Chrome 打开 `chrome://extensions`（Edge 中打开 `edge://extensions`），开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目根目录（其中包含 `manifest.json`）。
3. 如果目标网页在安装前已打开，或扩展已加载过旧版本，请刷新该网页；更新扩展后也要在扩展管理页重新加载。打开扩展弹窗并开启「显示收集按钮」。无需安装依赖或执行构建命令。

## 使用与验证

在普通 HTTP/HTTPS 网页双击一段文字，或按住鼠标拖拽选中一段文字后松开（例如 `example`），选区旁会显示「收集」按钮。普通单击不触发；**双击或拖拽本身不会保存**；点击「收集」后按钮消失，文字才会保存。点击页面别处、再次选词、滚动或调整窗口大小会关闭旧按钮，不保存该次选择。关闭开关后，双击文字不会显示按钮；如果按钮显示后才关闭开关，点击按钮也不会保存。

打开扩展弹窗的开发者工具控制台，执行：

```js
chrome.storage.local.get(null).then(console.log)
```

点击收集后，结果中应包含 `collectionEnabled: true` 和 `word:example: "example"`。再次收集相同内容不会新增另一条记录；首尾空白会去除、大小写不同视为不同内容，多个词会作为一整段保存。扩展不会上传数据。

## 查看与删除

打开扩展弹窗，在开关下方的「已收集」列表中查看所有保存的文字及条数。无记录时会显示空状态；词条较多时可以在列表内滚动。每条旁有「删除」按钮，点击后会从本地存储中移除**该条**，并立即更新列表；收集开关及其他记录不受影响。删除失败时词条会保留，可重试。词表查看和删除不依赖收集开关是否开启。

只在普通 HTTP/HTTPS 页面采集网页选区；浏览器内部页面、其他扩展页面以及输入框和可编辑区域的文字不在支持范围内。

## 自动化测试

需要 Node.js 20 或更新版本，无需安装依赖：

```sh
node --test
```
