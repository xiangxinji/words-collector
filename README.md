# Words Collector

一个无需构建步骤的 Chrome Manifest V3 扩展。开启收集后，在普通网页双击或拖拽选中文字，选区旁会出现「收集」按钮。**只有点击按钮才会保存**；收集与自动翻译开关在首次使用时都默认关闭。

## 安装

1. 使用 Chrome 103 或更新版本，在 `chrome://extensions`（Edge 可用 `edge://extensions`）开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的本项目根目录。无需安装依赖或构建。
3. 如果从 GitHub Release 下载 ZIP，先解压并选择包含 `manifest.json` 的目录加载。更新后在扩展管理页重新加载扩展；刷新此前已打开的目标网页。打开扩展弹窗，开启「显示收集按钮」。

## 收集与自动翻译

在普通 HTTP/HTTPS 网页双击或拖拽选择文字，再点击出现的「收集」按钮。普通单击、仅选择文字、仅显示按钮都不会保存或发送任何选区。点击网页别处、再次选词、滚动或调整窗口大小会关闭旧按钮。输入框及可编辑区域、浏览器内部页面和其他扩展页面不参与收集。

**不启用「收集时自动翻译成中文」时**：仅将去除首尾空白后的原文写入 `chrome.storage.local`，不向网络发送选中文字；同一原文只保留一条，区分大小写，多个词会作为一段保存。已带译文的词条不会因关闭翻译后再次收集而丢失译文。

**需要百度翻译时**：在弹窗底部展开「配置百度凭据」，输入自己的百度翻译开放平台 App ID 和密钥，点击「保存凭据」，再单独开启「收集时自动翻译成中文」。密钥框重开后保持空白；不修改 App ID 时留空保存会保留已存密钥，更换 App ID 时需重新输入密钥。只有两个开关都已开启、且你点击某次选区的「收集」按钮后，后台才将该次原文发送给百度通用文本翻译 API（自动识别原文语言，翻译成简体中文）。翻译成功后原文和译文一起保存在本机；如果缺少凭据、接口报错/超时或本地存储失败，则不新增该次词条，按钮会显示「重试」。如果请求进行中关闭收集开关，收到结果后不会保存；已发出的请求无法撤回。关闭自动翻译开关后，以后的收集又只在本地进行。

## 弹窗界面

弹窗采用紧凑的本地原生样式，依次展示收集开关、词表和可选的百度翻译设置。词条较多时词表可独立滚动；百度 App ID 和密钥默认收在「配置百度凭据」中，展开即可填写或更新。发送原文给百度的提示始终显示在设置区，折叠凭据不会更改两个开关的状态或发送时机。凭据保存成功显示成功提示，失败显示错误提示。

## 查看与删除

弹窗的「已收集」列表显示原文；翻译成功的词条还会显示译文。旧版本保存的纯文本词条继续可查看、删除，但不会自动补翻译。存储键仍为 `word:<原文>`，新词条的值现在包含原文与最近收集时间，例如 `{ text: "example", collectedAt: 1750000000000 }`；翻译成功时还包含 `translation`。点击某词条的「删除」只移除该词条，不影响其他词条、开关或凭据。删除失败时词条会保留供重试。

## 顺序、导出与导入

「已收集」按最近一次**成功收集**的时间倒序展示。同一个原文（区分大小写）只保留 `word:<原文>` 一条记录；再次点击「收集」会覆盖这条记录并更新其时间，使它回到最前面。关闭翻译时重收集会保留已有译文；收集失败则保留原词条，不会先删后存。旧版本没有时间的词条仍可查看、删除和导出，排在有时间的词条之后，旧词条之间按原文排序；无法恢复其真实收集时间，导出时标记为「未知（旧数据）」。如果新收集的词仍没有时间，请先在扩展管理页重新加载扩展、刷新目标网页再试。

点击「导出 CSV」下载 `words-collector.csv`（UTF-8，带 BOM，可用 Excel 等表格软件打开）。文件按列表顺序包含「原文」「译文」「最近收集时间（本地）」三列，不包含开关或百度凭据；没有词条时不可导出。为降低疑似公式的文本在表格软件中执行的风险，导出时会给相关单元格加前置制表符；导入由本扩展导出的 CSV 时会去掉这层保护。

点击「导入 CSV」选择该三列表头的 `.csv` 文件（上限 10 MB）；不支持直接导入 `.xlsx`。支持 BOM、双引号、逗号、换行和导出文件中的「未知（旧数据）」或空白时间；有时间的行必须使用 `YYYY-MM-DD HH:mm:ss` 本地时间格式。导入前完整校验文件，格式错误不写入任何词条；文件中和本地已有的同名词条由 CSV 的最后一行覆盖，导入后刷新词表。导入不修改开关或百度凭据，也不会发起网络请求。如果本地存储写入失败，会显示错误以便重试。

## 隐私、密钥与授权

- 内容脚本不能直接读取扩展本地存储；百度凭据仅保存在本机扩展存储，扩展只申请百度 API 域名的请求权限。无自建服务的纯客户端方案**不能保证密钥达到服务端保密级别**；请勿将 App ID 和密钥提交到仓库、聊天或截图中，也不要在网页的开发者工具里粘贴它们。
- 自动翻译开启时，只有你点击「收集」才会把该次原文交给百度；关闭翻译或仅查看列表时不会发送。扩展不会向其他服务发送选中文字，不会自动上传历史词条。
- [百度翻译开放平台公开协议](https://api.fanyi.baidu.com/api/trans/product/apidoc/)对客户端缓存翻译数据有约束。你选择的长期本地保存译文是否得到适用协议或额外授权允许，应在实际使用前自行核对；本项目不保证该用途符合百度条款。

## 手动验证

加载扩展后，先确认两个开关默认关闭。在翻译关闭时开启收集并选中 `example`，点击「收集」，在弹窗「已收集」列表中确认只出现原文。再在本地填写自己的 App ID/密钥、开启翻译，并在网页点击「收集」选区，确认弹窗同时显示原文与中文译文。可故意暂时填写错误凭据验证失败时不新增词条且可以重试，随后改回正确凭据。不要把密钥或实际选中文字输出到控制台。真实 API 的端到端验证需要你在本机完成；自动化测试使用模拟响应，不会使用真实凭据。还可依次收集 `apple`、`banana`，再次收集 `apple`，确认它只出现一次并排在最前；点击「导出 CSV」检查顺序、译文与本地时间列，再用「导入 CSV」选择该文件，确认重名词条只保留一条且开关和凭据不变。
