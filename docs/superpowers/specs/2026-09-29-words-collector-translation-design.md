# Words Collector 自动翻译设计

日期：2026-09-29

## 目标与成功标准

X 希望在现有「收集」操作中接入自己已有凭据的百度通用文本翻译 API。用户主动开启自动翻译并点击网页选区旁的「收集」后，扩展将原文（自动识别语言）翻译成简体中文；仅在拿到译文时，将原文和译文一起长期保存在本机，并在弹窗词表展示。无需构建器或自建服务；现有关闭翻译时的本地收集仍可用。

## 范围与用户控制

- `collectionEnabled` 沿用现有弹窗开关，缺省为 `false`；新增独立 `translationEnabled`，缺省为 `false`。仅两者都开启且用户点击「收集」时才可能向百度发送该次选中文字；只选中文字、展示按钮、查看词表、关闭任一开关均不触发翻译请求。
- 弹窗提供百度 App ID 和密钥的本地设置入口，密钥输入框遮蔽内容；仓库、日志及界面错误信息都不包含密钥或选中文字。不得要求用户在聊天中提供凭据。
- 百度翻译使用固定目标语言简体中文，源语言自动识别。仅请求固定的百度 API 域名，不对网页本身发送翻译请求。
- 内容脚本依旧忽略输入框/可编辑区域、空白选区；现有双击/拖拽、点击收集、关闭按钮的交互不变。

## 实现结构与数据流

1. `manifest.json` 增加后台 Service Worker 和**仅百度 API 域名**的 host permission；保持普通 HTTP/HTTPS 页面上的静态内容脚本及弹窗，无额外构建流程。具体接口参数、签名和域名在实现时以百度官方最新接入文档核对。
2. `popup.html` / `popup.js` 管理原有收集开关、新增翻译开关及 App ID/密钥；显示设置保存失败状态。仅通过扩展的可信上下文读取凭据。
3. `content.js` 在用户点击「收集」时向后台发送裁剪后的原文；后台校验消息来源、文本类型与非空、收集开关以及翻译开关。内容脚本不直接读取翻译凭据、不直接 fetch，也不直接写入词条。为了限制其读取凭据，在后台初始化时把 `chrome.storage.local` 的访问级别限制为可信扩展上下文；内容脚本与后台通信获取收集开关状态。网页无法调用可转发任意 URL 或读取配置的后台接口。
4. 未开启翻译时，后台沿用 `word:<原文>` 的独立键保存原文字符串；若该键已有译文，重复收集不得覆盖或清空译文。开启翻译时，后台以配置的 App ID/密钥对请求签名，仅向百度翻译该次原文；翻译成功后一次性写入 `{ text: 原文, translation: 译文 }`，不额外创建索引或自动补翻译旧词条。弹窗同时兼容旧版字符串值和新版对象值，删除仍只移除当前键。
5. 翻译期间按钮不可重复提交；成功后关闭按钮。翻译接口报错、超时、缺少凭据或存储失败时均不写入本次新词条、不回退覆盖已有词条，按钮保留并显示不含敏感内容的重试提示。若用户在请求期间关闭收集开关，返回后不得保存；已发出的请求不能撤销，此边界在 README 说明。后台异常不影响网页正常操作。

## 安全与使用限制

- 凭据只由用户填写并保存在本机扩展存储，不随源码提交；本地保存及限定可信上下文读取可降低网页脚本接触风险，但纯客户端无法达到服务端保密级别。除向百度签名请求外，不发送密钥或选中文字；不得在 URL 查询串、控制台日志、遥测或错误提示中泄漏这些内容。网络请求优先用 HTTPS POST 表单体，并以百度官方当前文档确认要求。
- 用户明确选择长期本地保存译文；已向用户提示[百度开放平台公开协议](https://api.fanyi.baidu.com/api/trans/product/apidoc/)第二部分第 2 款明言客户端程序不能缓存百度翻译数据（定义包括译文）；第 5 款提及可联系百度取得额外书面许可。X 明确选择持久保存，但没有确认已取得该许可。本设计不声称这种用途符合协议；上线或实际使用前需由 X 核对适用协议并取得必要授权。README 同时标明在线翻译会将点击收集的原文发送给百度，并区分关闭翻译的完全本地模式。
- 不新增后端、远程配置、云同步、自动重试队列、既有词条批量翻译或第三方依赖；不修改旧版纯文本记录的键格式。

## 验证与文档

- Node 内置测试模拟扩展 storage、消息、网络和弹窗，覆盖默认双开关关闭、无点击不请求、翻译关闭不请求、仅点击且开启翻译才发送、签名与 auto→zh 请求、成功原子保存和展示、重复收集保留译文、旧字符串词条展示与删除。
- 覆盖无凭据、API 报错/超时、存储失败、开关在请求中关闭、内容脚本不能读取凭据、错误不显示原文或密钥；各失败场景均不产生新词条，并允许点击重试。
- 修改 README 说明设置、隐私边界、失败与重试、历史数据兼容及手动验证；更新 AGENTS.md 的「从不联网」约束，明确仅在已开启翻译且点击收集时可向百度发送该次选中文字。
- `node --test` 必须通过，才声明实现完成；真实凭据的端到端手动测试由 X 在浏览器本地完成，不在测试/仓库中存放凭据。
